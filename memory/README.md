# Memory — những gì Muse biết về bạn

Bản sao trí nhớ của Muse về user, chụp ngày 26/10/2026, từ các file local:
`MEMORY.md`, `USER.md`, `PROACTIVE_PREFERENCES.md`, nhật ký ngày
(`daily/`), hồ sơ người liên quan (`people/`), nhóm (`groups/`) và kho
tổng hợp (`bank/`).

## Cấu trúc

- `MEMORY.md` — trí nhớ tinh gọn: sự thật bền vững, sở thích, ràng buộc,
  quyết định đã chốt, cam kết đang chạy.
- `USER.md` — bạn là ai, làm gì, múi giờ, điều bạn quan tâm.
- `PROACTIVE_PREFERENCES.md` — bạn muốn nghe chủ động về cái gì, khung giờ nào.
- `daily/` — nhật ký thô từng ngày (16–26/10/2026), chi tiết hơn bản tinh gọn.
- `people/` — những người/creator liên quan tới bạn (chủ yếu là tác giả bạn
  học theo cho Substack và các kênh).
- `groups/` — nhóm/cộng đồng (hiện chưa có).
- `bank/` — kho tổng hợp do hệ thống tự rút ra: experience (đã xảy ra),
  opinions (sở thích/quan điểm ổn định), world (sự thật bền vững),
  reflections (dòng suy ngẫm thô, file lớn nhất).

## Lưu ý đồng bộ

Đây là BẢN CHỤP tại thời điểm 26/10/2026, không tự cập nhật. Khi trí nhớ
local thay đổi (quyết định mới, sở thích mới, project mới), cần đẩy lại các
file tương ứng lên đây thì bản này mới khớp.

## Cảnh báo riêng tư — đọc kỹ

Repo này là private (chỉ tài khoản htvgitmod xem được trên github.com),
NHƯNG GitHub Pages là công khai: mọi file trong repo đều có thể mở được qua
đường link `htvgitmod.github.io/museofme/memory/...` nếu ai đó biết hoặc
đoán được đường dẫn. Nghĩa là: đừng coi folder này là "chỉ mình tôi đọc
được" theo nghĩa tuyệt đối. Nếu muốn giữ thật kín, cách an toàn hơn là
chuyển folder này sang một repo private RIÊNG KHÔNG bật GitHub Pages.

## Không có trong này

- Các file về bản thân Muse (SOUL.md, IDENTITY.md, AGENTS.md) — đó là về
  Muse, không phải về bạn, nên không đưa vào đây.
- Không có mật khẩu, token, mã OTP, số thẻ hay số tài khoản nào trong các
  file này (đã quét trước khi đẩy).
