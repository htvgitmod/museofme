## Quy ước làm việc

- **`source/` — một folder cho mỗi món đã chốt**, chỉ chứa file cuối. Bản nháp ở ngoài repo, chỉ đưa lên khi đã chốt.
- **File lớn (>1 MB) chỉ đưa lên bằng Upload Files**, không sửa bằng web editor GitHub — web editor từng làm rỗng file lớn.
- **Memory mirror: mỗi file một commit**, message đúng dạng `Memory mirror: <đường dẫn file>` (ví dụ `Memory mirror: memory/daily/2026-11-20.md`). Mirror chạy hằng ngày lúc 00:00 giờ Singapore.
- **Không đưa secret lên repo**: không mật khẩu, token, mã OTP, số thẻ, số tài khoản.
- Repo đang public — đừng đẩy nội dung riêng tư lên đây.
